### 一、函数、极限与连续

#### 1. 函数与数列极限

| 概念                                   | 区别                       |
| -------------------------------------- | -------------------------- |
| 函数极限 $\lim\limits_{x\to x_0}f(x)$  | $x$ 连续变化，趋近方式任意 |
| 数列极限 $\lim\limits_{n\to\infty}a_n$ | $n$ 离散变化，只能取正整数 |
| 左极限 $f(x_0^-)$                      | $x$ 从左侧趋近             |
| 右极限 $f(x_0^+)$                      | $x$ 从右侧趋近             |

**辨析：**

$$
\lim_{x\to x_0}f(x)\text{ 存在}
\iff
f(x_0^-)=f(x_0^+).
$$

数列极限存在不能推出对应函数极限存在。

#### 2. 无穷小与无穷大

| 概念   | 定义                      |
| ------ | ------------------------- |
| 无穷小 | $\lim f(x)=0$             |
| 无穷大 | $\lim                     | f(x) | =+\infty$ |
| 有界   | 存在 $M$，使 $            | f(x) | \le M$    |
| 无界   | 对任意 $M$，存在 $x$ 使 $ | f(x) | >M$       |

**辨析：**

- 无穷小 $\Rightarrow$ 局部有界，但无穷小不一定有界（整体）；
- 无穷大 $\Rightarrow$ 无界，但无界 $\not\Rightarrow$ 无穷大；
- 无穷小与无穷大互为倒数关系（非零时）。

#### 3. 连续、可导、可微

| 概念 | 关系                                                        |
| ---- | ----------------------------------------------------------- |
| 连续 | $\lim\limits_{x\to x_0}f(x)=f(x_0)$                         |
| 可导 | $\lim\limits_{\Delta x\to 0}\frac{\Delta y}{\Delta x}$ 存在 |
| 可微 | $\Delta y=A\Delta x+o(\Delta x)$                            |

**辨析：**

$$
\text{可微}\iff\text{可导}\Rightarrow\text{连续}
$$

$$
\text{连续}\nRightarrow\text{可导}
$$

反例：$f(x)=|x|$ 在 $x=0$ 处连续但不可导。

#### 4. 间断点分类

| 类型       | 条件                                             |
| ---------- | ------------------------------------------------ |
| 可去间断点 | $f(x_0^-)=f(x_0^+)\ne f(x_0)$ 或 $f(x_0)$ 无定义 |
| 跳跃间断点 | $f(x_0^-)\ne f(x_0^+)$                           |
| 无穷间断点 | 至少一侧极限为 $\infty$                          |
| 振荡间断点 | 极限不存在且不趋于 $\infty$                      |

**辨析：**

- 可去、跳跃为第一类间断点；
- 无穷、振荡为第二类间断点。

#### 5. 无穷小阶的比较

设 $\alpha,\beta$ 均为无穷小：

| 关系   | 条件                                |
| ------ | ----------------------------------- |
| 高阶   | $\lim\frac{\alpha}{\beta}=0$        |
| 同阶   | $\lim\frac{\alpha}{\beta}=c\ne 0$   |
| 等价   | $\lim\frac{\alpha}{\beta}=1$        |
| $k$ 阶 | $\lim\frac{\alpha}{\beta^k}=c\ne 0$ |
| 不可比 | $\lim\frac{\alpha}{\beta}$ 不存在   |

### 二、一元函数微分学

#### 1. 极值与最值

| 概念 | 区别                           |
| ---- | ------------------------------ |
| 极值 | 局部概念，某邻域内最大或最小   |
| 最值 | 整体概念，整个区间上最大或最小 |

**辨析：**

- 极值点不一定是驻点（不可导点也可能取极值）；
- 驻点不一定是极值点（如 $y=x^3$ 在 $x=0$）；
- 最值可能在端点、驻点或不可导点取得。

#### 2. 拐点与极值点

| 概念   | 条件       |
| ------ | ---------- |
| 极值点 | $f'$ 变号  |
| 拐点   | $f''$ 变号 |

**辨析：**

- 极值点是 $x$ 坐标，拐点是点 $(x_0,f(x_0))$；
- $f''(x_0)=0$ 不一定是拐点（如 $y=x^4$）；
- 拐点处不一定 $f''(x_0)=0$（不可导时）。

#### 3. 驻点、极值点、拐点

| 概念   | 定义           |
| ------ | -------------- |
| 驻点   | $f'(x_0)=0$    |
| 极值点 | 局部最大或最小 |
| 拐点   | 凹凸性改变     |

**辨析：**

$$
\text{极值点}\begin{cases}
\text{驻点}\\
\text{不可导点}
\end{cases}
$$

$$
\text{驻点}\nRightarrow\text{极值点}
$$

#### 4. 单调与凹凸

| 概念       | 条件         |
| ---------- | ------------ |
| 单调递增   | $f'(x)\ge 0$ |
| 单调递减   | $f'(x)\le 0$ |
| 凹（下凸） | $f''(x)>0$   |
| 凸（上凸） | $f''(x)<0$   |

**辨析：**

- 凹凸性定义在不同教材中可能相反，注意题目约定；
- $f'(x)>0$ 是严格单调递增的充分条件，非必要条件。

#### 5. 可导与连续

**辨析：**

$$
\text{可导}\Rightarrow\text{连续}\Rightarrow\text{极限存在}
$$

但反向均不成立。

#### 6. 渐近线

| 类型 | 条件                                                         |
| ---- | ------------------------------------------------------------ |
| 水平 | $\lim\limits_{x\to\infty}f(x)=A$                             |
| 垂直 | $\lim\limits_{x\to x_0}f(x)=\infty$                          |
| 斜   | $\lim\limits_{x\to\infty}\frac{f(x)}{x}=a,\ \lim[f(x)-ax]=b$ |

**辨析：**

- 水平渐近线与斜渐近线不能同时存在；
- 一个函数可以有多条垂直渐近线。

### 三、一元函数积分学

#### 1. 不定积分与定积分

| 概念     | 区别                     |
| -------- | ------------------------ |
| 不定积分 | 原函数族，含任意常数 $C$ |
| 定积分   | 一个确定的数             |
| 变限积分 | 关于上限的函数           |

**辨析：**

$$
\int_a^b f(x)\,dx=F(b)-F(a).
$$

不定积分是函数，定积分是数值。

#### 2. 原函数与可积

| 概念       | 条件                                       |
| ---------- | ------------------------------------------ |
| 原函数存在 | $f(x)$ 连续 $\Rightarrow$ 原函数存在       |
| 可积       | $f(x)$ 有界且间断点有限 $\Rightarrow$ 可积 |

**辨析：**

- 原函数存在不一定可积；
- 可积不一定原函数存在（如含跳跃间断点的函数）。

#### 3. 定积分与反常积分

| 概念     | 区别                         |
| -------- | ---------------------------- |
| 定积分   | 积分区间有限，被积函数有界   |
| 反常积分 | 积分区间无限，或被积函数无界 |

**辨析：**
反常积分通过极限定义：

$$
\int_a^{+\infty}f(x)\,dx=\lim_{b\to+\infty}\int_a^b f(x)\,dx.
$$

#### 4. 绝对收敛与条件收敛

| 概念     | 条件                  |
| -------- | --------------------- |
| 绝对收敛 | $\int                 | f   | $ 收敛 |
| 条件收敛 | $\int f$ 收敛但 $\int | f   | $ 发散 |

**辨析：**

$$
\text{绝对收敛}\Rightarrow\text{收敛}
$$

反向不成立。

#### 5. 定积分几何应用

| 概念          | 公式                            |
| ------------- | ------------------------------- |
| 面积          | $S=\int_a^b                     | f(x)-g(x) | \,dx$                |
| 绕 $x$ 轴体积 | $V=\pi\int_a^b f^2(x)\,dx$      |
| 绕 $y$ 轴体积 | $V=2\pi\int_a^b x               | f(x)      | \,dx$                |
| 弧长          | $s=\int_a^b\sqrt{1+(y')^2}\,dx$ |
| 旋转曲面面积  | $S=2\pi\int_a^b                 | y         | \sqrt{1+(y')^2}\,dx$ |

**辨析：**

- 体积与面积公式不同；
- 绕 $y$ 轴用柱壳法时注意 $x$ 为半径。

### 四、多元函数微分学

#### 1. 连续、偏导存在、可微

| 概念     | 关系                                       |
| -------- | ------------------------------------------ |
| 连续     | $\lim f(x,y)=f(x_0,y_0)$                   |
| 偏导存在 | $f_x,f_y$ 存在                             |
| 可微     | $\Delta z=f_x\Delta x+f_y\Delta y+o(\rho)$ |

**辨析：**

$$
\text{可微}\Rightarrow\text{连续}\Rightarrow\text{偏导存在}
$$

但反向均不成立。

**经典反例：**

$$
f(x,y)=
\begin{cases}
\dfrac{xy}{x^2+y^2},&(x,y)\ne(0,0),\\
0,&(x,y)=(0,0).
\end{cases}
$$

在 $(0,0)$ 处偏导存在但不连续，不可微。

#### 2. 偏导数连续与可微

$$
\text{偏导数连续}\Rightarrow\text{可微}
$$

反向不成立。

#### 3. 方向导数与偏导数

| 概念     | 关系                   |
| -------- | ---------------------- |
| 偏导数   | 沿坐标轴方向的方向导数 |
| 方向导数 | 沿任意方向             |
| 梯度     | 方向导数最大的方向     |

**辨析：**

$$
\frac{\partial f}{\partial l}=\nabla f\cdot\mathbf e_l.
$$

偏导数存在不保证方向导数存在；可微保证任意方向导数存在。

#### 4. 极值与最值

| 概念 | 区别                     |
| ---- | ------------------------ |
| 极值 | 局部概念                 |
| 最值 | 整体概念，可能在边界取得 |

**辨析：**

- 极值点一定是驻点或偏导不存在点；
- 驻点不一定是极值点；
- 条件极值用拉格朗日乘数法。

#### 5. 二重积分与二次积分

| 概念     | 区别         |
| -------- | ------------ |
| 二重积分 | 区域上的积分 |
| 二次积分 | 累次积分     |

**辨析：**

$$
\iint_D f\,d\sigma
=
\int_a^b dx\int_{\varphi_1(x)}^{\varphi_2(x)} f\,dy.
$$

二次积分是计算二重积分的方法，但二次积分存在不一定二重积分存在。

### 五、无穷级数

#### 1. 收敛与绝对收敛

| 概念     | 条件                      |
| -------- | ------------------------- |
| 收敛     | $\sum u_n$ 部分和极限存在 |
| 绝对收敛 | $\sum                     | u_n | $ 收敛 |
| 条件收敛 | $\sum u_n$ 收敛但 $\sum   | u_n | $ 发散 |

**辨析：**

$$
\text{绝对收敛}\Rightarrow\text{收敛}
$$

反向不成立。

#### 2. 正项级数审敛法

| 方法 | 条件                           |
| ---- | ------------------------------ |
| 比较 | $0\le u_n\le v_n$              |
| 比值 | $\lim\frac{u_{n+1}}{u_n}=\rho$ |
| 根值 | $\lim\sqrt[n]{u_n}=\rho$       |
| 积分 | $f(x)$ 单调递减非负            |

**辨析：**

- $\rho=1$ 时比值、根值法失效；
- 比较判别法需要找合适的参照级数。

#### 3. 幂级数收敛半径与收敛域

| 概念     | 区别                       |
| -------- | -------------------------- |
| 收敛半径 | $R$，由系数决定            |
| 收敛区间 | $(x_0-R,x_0+R)$            |
| 收敛域   | 收敛区间加上端点中收敛的点 |

**辨析：**
端点处必须单独判断，收敛域是收敛区间的子集或等于收敛区间。

#### 4. 函数项级数逐点收敛与一致收敛

| 概念     | 区别                 |
| -------- | -------------------- |
| 逐点收敛 | 对每个 $x$，级数收敛 |
| 一致收敛 | $N$ 与 $x$ 无关      |

**辨析：**

$$
\text{一致收敛}\Rightarrow\text{逐点收敛}
$$

反向不成立。

一致收敛保证和函数连续、可逐项积分、可逐项求导。

#### 5. 泰勒级数与傅里叶级数

| 概念       | 区别           |
| ---------- | -------------- |
| 泰勒级数   | 用幂函数逼近   |
| 傅里叶级数 | 用三角函数逼近 |

**辨析：**

- 泰勒级数在展开点附近逼近函数；
- 傅里叶级数在周期区间上逼近函数；
- 傅里叶级数在间断点收敛于左右极限平均值。

### 六、微分方程

#### 1. 通解与特解

| 概念 | 区别                         |
| ---- | ---------------------------- |
| 通解 | 含独立任意常数，个数等于阶数 |
| 特解 | 不含任意常数或已确定常数     |

**辨析：**
通解不一定包含所有解（如奇解），但线性方程通解包含所有解。

#### 2. 齐次与非齐次

| 概念   | 区别           |
| ------ | -------------- |
| 齐次   | 方程右端为零   |
| 非齐次 | 方程右端不为零 |

**辨析：**

$$
\text{非齐次通解}=\text{齐次通解}+\text{非齐次特解}.
$$

#### 3. 线性相关与线性无关

| 概念     | 条件                               |
| -------- | ---------------------------------- |
| 线性相关 | 存在不全为零的系数使线性组合为零   |
| 线性无关 | 只有全为零的系数才能使线性组合为零 |

**辨析：**

- 两个函数线性相关 $\iff$ 比值恒为常数；
- 朗斯基行列式不为零 $\Rightarrow$ 线性无关。

#### 4. 可分离变量与齐次方程

| 概念       | 形式                                            |
| ---------- | ----------------------------------------------- |
| 可分离变量 | $\frac{dy}{dx}=f(x)g(y)$                        |
| 齐次方程   | $\frac{dy}{dx}=\varphi\left(\frac{y}{x}\right)$ |

**辨析：**
齐次方程通过 $u=y/x$ 化为可分离变量方程。

### 七、线性代数

#### 1. 等价、相似、合同

| 概念 | 条件                          |
| ---- | ----------------------------- |
| 等价 | 存在可逆 $P,Q$，使 $PAQ=B$    |
| 相似 | 存在可逆 $P$，使 $P^{-1}AP=B$ |
| 合同 | 存在可逆 $C$，使 $C^TAC=B$    |

**辨析：**

$$
\text{相似}\Rightarrow\text{等价},\qquad
\text{合同}\Rightarrow\text{等价}
$$

对实对称矩阵：

$$
\text{相似}\Rightarrow\text{合同}\Rightarrow\text{等价}
$$

反向一般不成立。

#### 2. 矩阵的秩

| 概念     | 关系         |
| -------- | ------------ |
| 行秩     | 行向量组的秩 |
| 列秩     | 列向量组的秩 |
| 矩阵的秩 | 行秩 = 列秩  |

**辨析：**

$$
r(A)=r(A^T)=r(A^TA)=r(AA^T).
$$

#### 3. 可逆与满秩

**辨析：**

$$
A\text{ 可逆}\iff |A|\ne 0\iff r(A)=n\iff Ax=0\text{ 只有零解}
$$

$$
\iff 0\text{ 不是特征值}.
$$

#### 4. 特征值与特征向量

| 概念       | 条件                        |
| ---------- | --------------------------- |
| 特征值     | $                           | \lambda I-A | =0$ 的根 |
| 特征向量   | $(\lambda I-A)x=0$ 的非零解 |
| 特征子空间 | $(\lambda I-A)x=0$ 的解空间 |

**辨析：**

- 特征向量必须非零；
- 同一特征值的特征向量不一定线性无关；
- 不同特征值的特征向量线性无关。

#### 5. 相似对角化与可对角化

| 概念       | 条件                                |
| ---------- | ----------------------------------- |
| 可对角化   | 存在可逆 $P$，使 $P^{-1}AP=\Lambda$ |
| 相似对角化 | 同上                                |

**辨析：**

$$
A\text{ 可对角化}
\iff
A\text{ 有 }n\text{ 个线性无关的特征向量}
$$

$$
\iff
\text{每个特征值的几何重数}=\text{代数重数}.
$$

#### 6. 正定与半正定

| 概念   | 条件                       |
| ------ | -------------------------- |
| 正定   | $\forall x\ne 0,\ x^TAx>0$ |
| 半正定 | $\forall x,\ x^TAx\ge 0$   |
| 负定   | $\forall x\ne 0,\ x^TAx<0$ |

**辨析：**

- 正定要求特征值全为正；
- 半正定要求特征值全非负；
- 正定矩阵一定可逆，半正定不一定。

#### 7. 伴随矩阵的秩

$$
r(A^*)=
\begin{cases}
n,& r(A)=n,\\
1,& r(A)=n-1,\\
0,& r(A)\le n-2.
\end{cases}
$$

**辨析：**
注意 $r(A)=n-1$ 时 $r(A^*)=1$，不是 $0$。

#### 8. 向量组线性相关与矩阵可逆

| 概念           | 关系                             |
| -------------- | -------------------------------- |
| 向量组线性相关 | 存在不全为零的系数使线性组合为零 |
| 矩阵可逆       | 列向量组线性无关                 |

**辨析：**

$$
A\text{ 可逆}\iff A\text{ 的列向量组线性无关}.
$$

### 八、概率论与数理统计

#### 1. 互斥与独立

| 概念 | 条件                        |
| ---- | --------------------------- |
| 互斥 | $AB=\varnothing$，$P(AB)=0$ |
| 独立 | $P(AB)=P(A)P(B)$            |

**辨析：**

- 互斥不一定独立；
- 独立不一定互斥；
- 若 $P(A)>0,P(B)>0$，互斥与独立不能同时成立。

#### 2. 概率为零与不可能事件

**辨析：**

$$
P(A)=0\nRightarrow A=\varnothing.
$$

概率为零的事件不一定是不可能事件（连续型随机变量取单点值）。

#### 3. 分布函数与概率密度

| 概念     | 关系                   |
| -------- | ---------------------- |
| 分布函数 | $F(x)=P(X\le x)$       |
| 概率密度 | $f(x)=F'(x)$（连续型） |

**辨析：**

- 离散型用分布律，连续型用概率密度；
- 分布函数一定右连续。

#### 4. 期望与方差

| 概念 | 公式                   |
| ---- | ---------------------- |
| 期望 | $E(X)$                 |
| 方差 | $D(X)=E(X^2)-[E(X)]^2$ |

**辨析：**

$$
D(aX+b)=a^2D(X).
$$

$$
E(aX+b)=aE(X)+b.
$$

#### 5. 独立与不相关

| 概念   | 条件                        |
| ------ | --------------------------- |
| 独立   | $f(x,y)=f_X(x)f_Y(y)$       |
| 不相关 | $\operatorname{Cov}(X,Y)=0$ |

**辨析：**

$$
\text{独立}\Rightarrow\text{不相关}
$$

反向不成立（正态分布除外）。

#### 6. 大数定律与中心极限定理

| 概念         | 区别                     |
| ------------ | ------------------------ |
| 大数定律     | 样本均值依概率收敛于期望 |
| 中心极限定理 | 样本均值近似服从正态分布 |

**辨析：**

- 大数定律说明稳定性；
- 中心极限定理说明分布近似。

#### 7. 矩估计与最大似然估计

| 概念         | 方法               |
| ------------ | ------------------ |
| 矩估计       | 用样本矩代替总体矩 |
| 最大似然估计 | 最大化似然函数     |

**辨析：**

- 矩估计不唯一；
- 最大似然估计不一定无偏；
- 两者可能相同也可能不同。

#### 8. 无偏性与有效性

| 概念 | 条件                   |
| ---- | ---------------------- |
| 无偏 | $E(\hat\theta)=\theta$ |
| 有效 | 方差最小               |
| 一致 | 依概率收敛于 $\theta$  |

**辨析：**
无偏不一定有效，有效不一定无偏。

### 九、易混淆概念总结

#### 1. 高数部分

| 易混淆               | 关键区别                   |
| -------------------- | -------------------------- |
| 连续 vs 可导         | 可导必连续，反之不然       |
| 可导 vs 可微         | 一元函数中等价             |
| 极值 vs 最值         | 局部 vs 整体               |
| 驻点 vs 极值点       | 驻点不一定是极值点         |
| 拐点 vs 极值点       | $f''$ 变号 vs $f'$ 变号    |
| 原函数 vs 可积       | 连续有原函数，可积要求有界 |
| 绝对收敛 vs 条件收敛 | 绝对值级数是否收敛         |
| 逐点收敛 vs 一致收敛 | $N$ 是否与 $x$ 有关        |
| 偏导存在 vs 可微     | 可微必偏导存在，反之不然   |
| 二重积分 vs 二次积分 | 区域积分 vs 累次积分       |

#### 2. 线代部分

| 易混淆               | 关键区别                     |
| -------------------- | ---------------------------- |
| 等价 vs 相似 vs 合同 | 条件不同，相似合同都要求可逆 |
| 相似 vs 合同         | 相似保特征值，合同保惯性指数 |
| 可逆 vs 满秩         | 等价                         |
| 线性相关 vs 线性无关 | 是否存在非零系数             |
| 特征值 vs 特征向量   | 数值 vs 向量                 |
| 正定 vs 半正定       | 严格大于 vs 大于等于         |
| 伴随矩阵秩           | 分三种情况                   |

#### 3. 概率部分

| 易混淆               | 关键区别                      |
| -------------------- | ----------------------------- |
| 互斥 vs 独立         | $P(AB)=0$ vs $P(AB)=P(A)P(B)$ |
| 独立 vs 不相关       | 独立更强                      |
| 概率为零 vs 不可能   | 概率为零不一定不可能          |
| 分布函数 vs 概率密度 | 离散 vs 连续                  |
| 期望 vs 方差         | 中心位置 vs 离散程度          |
| 无偏 vs 有效         | 均值 vs 方差                  |
| 大数定律 vs 中心极限 | 收敛 vs 分布近似              |

### 十、概念题解题策略

#### 1. 判断命题真假

- 举反例：找满足条件但不满足结论的例子；
- 严格证明：从定义出发逻辑推理；
- 利用等价条件：转化为已知等价命题。

#### 2. 选择题技巧

- 排除法：排除明显错误选项；
- 特殊值法：代入特殊函数或数值验证；
- 反例法：构造反例排除选项；
- 定义法：直接根据定义判断。

#### 3. 常见陷阱

- 充分条件与必要条件混淆；
- 连续、可导、可微关系误判；
- 相似、合同、等价关系混淆；
- 互斥与独立混淆；
- 收敛与绝对收敛混淆；
- 一致收敛与逐点收敛混淆。

#### 4. 答题规范

- 明确写出判断依据；
- 反例要具体、完整；
- 证明要逻辑清晰；
- 注意条件与结论的对应关系。
