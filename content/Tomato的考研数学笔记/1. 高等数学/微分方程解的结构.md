### 速记表

| **已知条件**                   | **推出结论**                                | **典型应用/意义**                                                    |
| ------------------------------ | ------------------------------------------- | -------------------------------------------------------------------- |
| **$y_1, y_2$ 为非齐次解**      | $y_1 - y_2$ 为齐次解                        | 求 $p(x)$ 时可利用齐次方程带入                                       |
| **$y_1, y_2$ 为非齐次解**      | $\frac{y_1 + y_2}{2}$ 为非齐次解            | 系数和为 $1/2 + 1/2 = 1$                                             |
| **$y_1, y_2, y_3$ 为非齐次解** | $y_2 - y_1$ 与 $y_3 - y_1$ 为两个齐次解     | 若两者线性无关，可直接构造二阶齐次通解 $C_1(y_2-y_1) + C_2(y_3-y_1)$ |
| **$y_1, y_2, y_3$ 为非齐次解** | $y = y_1 + C_1(y_2 - y_1) + C_2(y_3 - y_1)$ | 二阶非齐次方程的完整通解表达                                         |

### 一、 齐次线性微分方程解的结构

以 $n$ 阶齐次线性微分方程为例：

$$y^{(n)} + a_1(x)y^{(n-1)} + \cdots + a_{n-1}(x)y' + a_n(x)y = 0 \quad (\text{E}_0)$$

1. **特解线性组合为还是特解解**：

   若 $y_1(x), y_2(x), \dots, y_k(x)$ 是 $(\text{E}_0)$ 的解，则它们的线性组合：

   $$y = C_1 y_1(x) + C_2 y_2(x) + \cdots + C_k y_k(x)$$

   仍然是 $(\text{E}_0)$ 的解（其中 $C_i$ 为任意常数）。

2. **齐次通解定理**：

   若 $y_1(x), y_2(x), \dots, y_n(x)$ 是 $(\text{E}_0)$ 的 **$n$ 个线性无关** 的解，则 $(\text{E}_0)$ 的**通解**为：

   $$y_0(x) = C_1 y_1(x) + C_2 y_2(x) + \cdots + C_n y_n(x)$$

   _注：对于一阶齐次，需要 1 个线性无关解；对于二阶齐次，需要 2 个线性无关解（类比线性代数中解向量的维数）。_

### 二、 非齐次线性微分方程解的结构

非齐次线性微分方程：

$$y^{(n)} + a_1(x)y^{(n-1)} + \cdots + a_{n-1}(x)y' + a_n(x)y = f(x) \quad (\text{E})$$

1. **非齐次通解定理（非齐次通解 = 齐次通解 + 非齐次特解）**：

   设 $y^*(x)$ 是非齐次方程 $(\text{E})$ 的一个**特解**，$Y(x)$ 是对应齐次方程 $(\text{E}_0)$ 的**通解**，则非齐次方程 $(\text{E})$ 的**通解**为：

   $$y(x) = Y(x) + y^*(x)$$

2. **解的差值性质（减法法则）**：

   若 $y_1(x)$ 与 $y_2(x)$ 均为非齐次方程 $(\text{E})$ 的解，则它们的差 $y_1(x) - y_2(x)$ 是对应齐次方程 $(\text{E}_0)$ 的**解**。

3. **解的加权叠加性质（线性组合法则）**：

   若 $y_1, y_2, \dots, y_k$ 是非齐次方程 $(\text{E})$ 的解，则线性组合：

   $$y = k_1 y_1 + k_2 y_2 + \cdots + k_k y_k$$

   - 当 $\sum_{i=1}^k k_i = 0$ 时，该组合是对应**齐次方程 $(\text{E}_0)$ 的解**；

   - 当 $\sum_{i=1}^k k_i = 1$ 时，该组合是**非齐次方程 $(\text{E})$ 的解**。

4. **右端项叠加原理（拆分叠加）**：

   若 $y_1^*(x)$ 是方程 $L[y] = f_1(x)$ 的特解，$y_2^*(x)$ 是方程 $L[y] = f_2(x)$ 的特解，则 $y_1^*(x) + y_2^*(x)$ 是方程：

   $$L[y] = f_1(x) + f_2(x)$$

   的**特解**。

> [!note]- (3) 详细解析 [答案：(A)]
> **【解】** 设 $y_1 = (1+x^2)^2 - \sqrt{1+x^2}$, $y_2 = (1+x^2)^2 + \sqrt{1+x^2}$。
>
> 由线性微分方程解的结构得 $y_2 - y_1 = 2\sqrt{1+x^2}$ 为 $y' + p(x)y = 0$ 的解，
>
> 代入得：
> $$\frac{2x}{\sqrt{1+x^2}} + p(x) \cdot 2\sqrt{1+x^2} = 0 \implies p(x) = -\frac{x}{1+x^2}$$
>
> 再由线性微分方程解的结构，得特解 $y^* = \frac{y_1 + y_2}{2} = (1+x^2)^2$ 为 $y' + p(x)y = q(x)$ 的解，代入得：
> $$4x(1+x^2) - \frac{x}{1+x^2} \cdot (1+x^2)^2 = q(x)$$
>
> 解得：$q(x) = 3x(1+x^2)$
>
> **故选 (A)**
