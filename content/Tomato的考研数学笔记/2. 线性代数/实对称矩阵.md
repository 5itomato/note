### 定义

设 $A = (a_{ij})$ 为 $n$ 阶**实矩阵**，若满足
$$A^{\mathrm{T}} = A \quad (\text{即 } a_{ij} = a_{ji},\ i,j = 1,\dots,n)$$
则称 $A$ 为**实对称矩阵**。

### 充要条件（当且仅当）

1. $A^{\mathrm{T}} = A$；
2. **谱定理**：存在[[正交矩阵]] $Q$，使$$Q^{-1}AQ = Q^{\mathrm{T}}AQ = \operatorname{diag}(\lambda_1,\dots,\lambda_n),\quad \lambda_i \in \mathbb{R}$$即 $A$ **可正交相似对角化**（$\Leftarrow$ 亦成立：若 $A = Q\Lambda Q^{\mathrm{T}}$ 且 $\Lambda$ 实对角，则 $A^{\mathrm{T}} = A$）；
3. $A = \sum_{i=1}^{n} \lambda_i q_i q_i^{\mathrm{T}}$，其中 $q_i$ 为单位正交特征向量（谱分解）。

### 必要条件

1.  **特征值全为实数**（普通实矩阵只能保证复特征值成对共轭）；
2. **必可对角化**，即 $A \sim \Lambda$；进而对 $k$ 重特征值 $\lambda$，有$$\dim V_\lambda = k,\qquad \operatorname{r}(\lambda E - A) = n - k$$
3. **属于不同特征值的特征向量必正交**（普通矩阵只有"线性无关"）。
4. $\operatorname{tr}(A) = \sum \lambda_i,\ |A| = \prod \lambda_i,\ \operatorname{r}(A) =$ 非零特征值个数。

### 其他性质

1. **正交化只需组内进行**：不同特征值的特征向量已自动正交，只需对**同一特征值的 $k$ 个特征向量**做 Schmidt 正交化再单位化。
2. **$A$ 实对称且 $A^{2} = O \Rightarrow A = O$**（由 $A^{\mathrm{T}}A = A^{2} = O$ 得每列为 $0$）。一般矩阵无此结论。
3. **幂与函数的计算**：$A = Q\Lambda Q^{\mathrm{T}} \Rightarrow A^{n} = Q\Lambda^{n}Q^{\mathrm{T}}$；$kE+A$、$A^{-1}$（若$A$可逆）、$A^{*}$ 的特征值分别为 $k+\lambda_i$、$\lambda_i^{-1}$、$|A|/\lambda_i$。
4. **相似与合同的关系**：
    - 实对称矩阵 $A \sim B \Rightarrow A \simeq B$（合同），**反之不成立**；
    - $A \simeq B \iff$ 正、负惯性指数分别相同（惯性定理）。
5. **正定**：$A$ 实对称时，$$A \text{ 正定} \iff \text{特征值全}>0 \iff \text{各阶顺序主子式全}>0 \iff \exists \text{ 可逆 } P,\ A = P^{\mathrm{T}}P \iff A \simeq E$$
