### 定义

设 $\boldsymbol{A}$ 为 $n$ 阶方阵，若满足
$$\boldsymbol{A}^{\mathrm{T}}\boldsymbol{A} = \boldsymbol{E} \quad ( \boldsymbol{A}\boldsymbol{A}^{\mathrm{T}} = \boldsymbol{E}， \boldsymbol{A}^{-1} = \boldsymbol{A}^{\mathrm{T}})$$
则称 $\boldsymbol{A}$ 为正交矩阵。

>正交矩阵必须是方阵。若 $\boldsymbol{A}$ 为 $m \times n$ 非方阵且 $\boldsymbol{A}^{\mathrm{T}}\boldsymbol{A} = \boldsymbol{E}$，只能说明其列向量组标准正交，$\boldsymbol{A}$ 不是正交矩阵。

### 充要条件（当且仅当）

1. $\boldsymbol{A}^{\mathrm{T}}\boldsymbol{A} = \boldsymbol{E}$ 或 $\boldsymbol{A}\boldsymbol{A}^{\mathrm{T}} = \boldsymbol{E}$；
2. $\boldsymbol{A}^{-1} = \boldsymbol{A}^{\mathrm{T}}$；
3. $\boldsymbol{A}$ 的列向量组为 $\mathbb{R}^n$ 的一组标准正交基；
4. $\boldsymbol{A}$ 的行向量组为 $\mathbb{R}^n$ 的一组标准正交基；
5. $\boldsymbol{A}^{\mathrm{T}}$、$\boldsymbol{A}^{-1}$ 也是正交矩阵。

### 必要条件

1. $|\boldsymbol{A}| = \pm 1$；
2. $\boldsymbol{A}$ 可逆；
3. $\boldsymbol{A}$ 的实特征值只能为 $\pm 1$。

### 其他性质

1. 运算封闭：$\boldsymbol{A}, \boldsymbol{B}$ 正交 $\Rightarrow \boldsymbol{A}\boldsymbol{B}$ 正交，$\boldsymbol{A}^{\mathrm{T}} = \boldsymbol{A}^{-1}$ 正交；但正交矩阵之和一般不是正交矩阵。
2. 伴随矩阵：$\boldsymbol{A}^* = |\boldsymbol{A}|\boldsymbol{A}^{-1} = |\boldsymbol{A}|\boldsymbol{A}^{\mathrm{T}}$，仍为正交矩阵。
3. 正交变换 $\boldsymbol{x} \mapsto \boldsymbol{A}\boldsymbol{x}$ 保持向量内积、长度、夹角及正交性不变。
4. [[实对称矩阵]]必可正交相似对角化：存在正交矩阵 $\boldsymbol{Q}$，使 $\boldsymbol{Q}^{-1}\boldsymbol{A}\boldsymbol{Q} = \boldsymbol{Q}^{\mathrm{T}}\boldsymbol{A}\boldsymbol{Q} = \boldsymbol{\Lambda}$，主对角元素即 $\boldsymbol{A}$ 的全部特征值。
5. 推论：
- $\boldsymbol{A}$ 正交且 $|\boldsymbol{A}| = -1 \Rightarrow |\boldsymbol{A} + \boldsymbol{E}| = 0$，即 $-1$ 必为 $\boldsymbol{A}$ 的特征值；
- $\boldsymbol{A}$ 正交、$|\boldsymbol{A}| = 1$ 且 $n$ 为奇数 $\Rightarrow |\boldsymbol{A} - \boldsymbol{E}| = 0$，即 $1$ 必为 $\boldsymbol{A}$ 的特征值；
- $\boldsymbol{A}$ 正交且对称（$\boldsymbol{A}^{\mathrm{T}} = \boldsymbol{A}$）$\Rightarrow \boldsymbol{A}^2 = \boldsymbol{E}$，特征值只能是 $\pm 1$。
- **正交变换化二次型为标准形**：$x = Qy$（$Q$ 正交），标准形系数为特征值 $\lambda_i$；与配方法（一般可逆变换）所得标准形系数一般不是特征值，但规范形由正负惯性指数唯一确定。
