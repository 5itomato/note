# 0. 杂项

这里有杂乱的知识及公式总结，还有学习心得。

## 内容

1. 行和定值 → 特征值等于该行和，特征向量是全1向量

> 设矩阵 $A$ 为 $n \times n$ 的方阵，若矩阵 $A$ 的**每一行元素之和都等于常数 $k$**，那么：
> **$k$ 必为矩阵 $A$ 的一个特征值**
> **$x = (1, 1, \dots, 1)^T$（全 1 向量）是 $A$ 对应于特征值 $k$ 的特征向量**

2. 微分方程解的结构（详见 [[Tomato的考研数学笔记/1. 高等数学/微分方程解的结构|微分方程解的结构]]）

| **已知条件**                   | **推出结论**                                | **典型应用/意义**                                                    |
| ------------------------------ | ------------------------------------------- | -------------------------------------------------------------------- |
| **$y_1, y_2$ 为非齐次解**      | $y_1 - y_2$ 为齐次解                        | 求 $p(x)$ 时可利用齐次方程带入                                       |
| **$y_1, y_2$ 为非齐次解**      | $\frac{y_1 + y_2}{2}$ 为非齐次解            | 系数和为 $1/2 + 1/2 = 1$                                             |
| **$y_1, y_2, y_3$ 为非齐次解** | $y_2 - y_1$ 与 $y_3 - y_1$ 为两个齐次解     | 若两者线性无关，可直接构造二阶齐次通解 $C_1(y_2-y_1) + C_2(y_3-y_1)$ |
| **$y_1, y_2, y_3$ 为非齐次解** | $y = y_1 + C_1(y_2 - y_1) + C_2(y_3 - y_1)$ | 二阶非齐次方程的完整通解表达                                         |

3. 秩与 $A^TA$（详见 [[Tomato的考研数学笔记/2. 线性代数/矩阵的秩|矩阵的秩]]）：

$$
r(A^TA)=r(A)=r(AA^T).
$$

4. $(u^Tv)^2=v^Tuu^Tv$
   $u^Tv$为标量，其转置为它本身，因此$(u^Tv)^2=(u^Tv)^T(u^Tv)=(v^Tu)(u^Tv)$
   此结论在二次型中常有应用，如$(\alpha^Tx)^2=(x^T\alpha)(\alpha^Tx)=x^T(\alpha\alpha^T)x$可以表示一个二次型。

5. 二次型矩阵 $A$ 经正交变换 $x=Qy$ 化为二次型矩阵 $B$，则 $A\sim B$
   若仅是可逆变换 $x=Cy$，则 $A\simeq B$（详见 [[Tomato的考研数学笔记/2. 线性代数/二次型|二次型]]）
